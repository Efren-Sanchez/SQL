# Puntos de conflicto más importantes entre SQL de MySQL, PostgreSQL y Oracle XE

### 1. Funciones de Fecha (El mayor problema)  
  
        MySQL: MONTH(fecha), YEAR(fecha), DAYNAME(fecha).  
        PostgreSQL: EXTRACT(MONTH FROM fecha) o to_char(fecha, 'Month').  
        Oracle: EXTRACT(MONTH FROM fecha) o to_char(fecha, 'MONTH').  
    
        MySQL: NOW(), CURDATE().  
        PostgreSQL: now(), CURRENT_DATE.  
        Oracle: SYSDATE.  
  
### 2. Paginación (LIMIT y OFFSET)  
  
        MySQL y PostgreSQL: Usan LIMIT 10 OFFSET 50. Esto es compatible entre ambos.  
        Oracle XE: Históricamente no usaba LIMIT. En versiones modernas (12c en adelante) se usa OFFSET 50 ROWS FETCH NEXT 10 ROWS ONLY. En versiones antiguas se usaba una   subconsulta con ROWNUM.  
  
### 3. Concatenación de Cadenas  
  
        MySQL: CONCAT(a, b, c).  
        PostgreSQL y Oracle: El estándar es el operador de doble barra a || b || c. Aunque CONCAT existe, en Oracle solo acepta dos argumentos.  
  
### 4. Longitud de cadena  
  
        MySQL: CHAR_LENGTH().  
        PostgreSQL y Oracle: LENGTH().  
  
### 5. Actualizaciones con JOIN (DML avanzado)  
  
        MySQL: UPDATE tabla1 JOIN tabla2 ON ... SET tabla1.col = val.  
        PostgreSQL: UPDATE tabla1 SET col = val FROM tabla2 WHERE ....  
        Oracle: No permite JOIN directamente en el UPDATE. Se debe usar una subconsulta o una vista actualizable (UPDATE (SELECT ...) SET ...).  
  
### 6. Tipos de datos y Auto-incremento  
  
        MySQL: INT UNSIGNED AUTO_INCREMENT.  
        PostgreSQL: SERIAL o INT GENERATED ALWAYS AS IDENTITY.  
        Oracle: NUMBER GENERATED BY DEFAULT AS IDENTITY.  
    
        MySQL: El tipo ENUM es nativo.  
        PostgreSQL: Debes crear un tipo CREATE TYPE primero.  
        Oracle: No existe ENUM, se debe usar una restricción CHECK (columna IN ('Valor1', 'Valor2')).  

### Tabla de Compatibilidad Quick-Look

| Elemento | MySQL | PostgreSQL | Oracle XE |
| --- | --- | --- | --- | 
| Paginación | LIMIT | LIMIT | FETCH NEXT |
| Día/Mes/Año | MONTH() | EXTRACT() | EXTRACT() |
| Concatenar | CONCAT() | || | || |
| Auto-incremento | AUTO_INCREMENT | SERIAL / IDENTITY | IDENTITY |
| Booleanos | TINYINT(1) | BOOLEAN	NUMBER(1) |
| Falsos JOINs en UPDATE | Soportado | FROM clause | Subconsultas |
